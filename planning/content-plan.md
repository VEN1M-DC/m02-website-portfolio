# Portfolio design plan

Author: Isa Samiezade-Yazd. Prepared with AI assistance; review before submission.

## Home — index.html
Introduce Isa as a student working with Python, Django, and accessible web development. Show an original browser diagram, links to the Projects and About pages, and three areas of study. Use Bootstrap buttons and a responsive grid.

## Projects — projects.html
Feature the existing individual course documentation repository and the team documentation repository. Explain scope, source material, and individual versus collaborative ownership. Use Bootstrap cards, two original diagrams, and direct repository links. Stack the cards on small screens.

## About — about.html
Explain the portfolio's learning focus, describe the build/test/revise approach, and link to five relevant official learning resources. Use a Bootstrap list group. Do not invent professional experience, completed applications, or personal contact details.

## Navigation and visual design
Home ↔ Projects ↔ About through nav.html on every page. Always-visible navigation, dark green ink, warm paper background, yellow accents, underlined text links, generous spacing. All paths relative for GitHub Pages repository hosting. Preserve fallback links if the navigation fetch fails.

## Verification plan
Check each page at desktop and 375px/320px widths, keyboard focus and skip links, loaded images, current-page state, local links, and contrast. Run WAVE on the deployed site and retain real screenshots; do not substitute a checklist for WAVE evidence.
